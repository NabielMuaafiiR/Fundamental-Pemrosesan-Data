# Fundamental Pemrosesan Data

Repositori ini berisi implementasi dasar pemrosesan data menggunakan Python. Proyek ini difokuskan pada pemahaman teknik-teknik dasar pengolahan data, pemrograman, serta penyusunan skrip untuk berbagai kebutuhan data.

## Deskripsi

Tujuan utama dari proyek ini adalah memberikan pemahaman menyeluruh terkait pemrosesan data menggunakan Python. Di dalamnya, digunakan berbagai teknik untuk mengambil, memanipulasi, dan mengolah data dari berbagai sumber. Proyek ini relevan dalam berbagai konteks seperti analisis data, *web scraping*, dan aplikasi lainnya.

## Fitur

Berikut adalah fitur utama yang tersedia dalam proyek ini:

- **Web Scraping**: Mengambil data dari situs web dan mengolahnya menjadi informasi yang dapat digunakan lebih lanjut.
- **Transformasi Data**: Mengonversi data mentah menjadi format yang terstruktur dan siap dianalisis.
- **Pengujian Unit**: Menggunakan *unit testing* untuk memverifikasi bahwa fungsi-fungsi bekerja dengan benar.

## Instalasi

Pastikan Python telah terinstal pada sistem Anda. Jika proyek memiliki dependensi eksternal, semua pustaka yang dibutuhkan tersedia di file `requirements.txt`.

### 1. Kloning Repositori

Jalankan perintah berikut di terminal untuk mengunduh proyek:

```bash
git clone https://github.com/NabielMuaafiiR/Fundamental-Pemrosesan-Data.git
cd Fundamental-Pemrosesan-Data

### 2. Instalasi Dependensi

pip install -r requirements.txt

### Langkah 3: Menjalankan Skrip Utama

python main.py

### Langkah 4: Menjalankan Unit Test

python -m unittest discover tests


### Langkah 5: Menjalankan Test Coverage

coverage run -m unittest discover tests

### Langkah 6: Melihat Hasil Laporan Coverage

coverage report -m
